## WHAT
This folder contains the Jupyter notebook **transient_dynamics.ipynb**, used in the current version of the manuscript to simulate the phage-bacteria model (with and without carrying capacity), identify relevant processes and compare the adaptive Boolean model with the full model. The earlier code that inspired it (needle-finder, **sergio_model-legacy/Metamodel**) is preserved in the `legacy` branch and the `v0.1.0-alpha` pre-release.
