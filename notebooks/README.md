## WHAT

Within this folder is the original code that inspired the current code 'sergio_model-artifiact/Metamodel' which contains the code that inspired the more recent code utilized in the manuscript, "Finite Observation Framework Predicts Tipping Points in Transient Dynamics." The Juptyer notebook labeled 'transient-dynamics' is the notebook which is utilized within the current version manuscript and differs from the original code, being inspired but not building off the code.
