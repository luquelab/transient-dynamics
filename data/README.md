# WHAT
This folder contains the data for the current model used in the manuscript, in **transient-dynamics_output-current**. Data from the earlier version of the project are preserved in the `legacy` branch and the `v0.1.0-alpha` pre-release.

The **transient-dynamics_output-current** folder contains two subfolders: **data_output** and **example_scenarios**. The **data_output** folder is where the notebook writes its outputs (folder **generated-data**), with figures and stored variables divided by model type. The **example_scenarios** folder is divided into **carrying_capacity_model** and **standard_model**; each scenario listed in the manuscript has an `input.txt` file to replicate it and the stored outputs for comparison. The **data_output_dict.md** file describes the columns of the Excel files of array variables produced by the simulations.
