# WHAT
This folder contains the data sets for each parameter set, including the intial parameters, graphs (for population change, processes vs time, weights vs time, and error between the full and adaptive model), and lastly the export of the generated values for the agent, weights and error for each point in time. The folder labelled, `sergio_data-legacy` is data from the original model that inspired this new project. The folder labeled, `transient-dynamics_output-current` contains the data from the current model that is used within the manuscript, as stated previously it contains output files and unedited figures.  

The `transient-dynamic_output-current` folder contains two subfolders: `data_output` and `example_outputs`. The `data_output` folder contains the folder `generated_data` from which one can find the outputs in terms of figures and stored variables/analysis from simulation that is divided based upon type of model. `example_outputs` folder contains a folder for each given scenario as listed in the manuscript including a file to replicate the data and the stored data for each of those scenarios for comparison. To aid in comparison of the individual generated data and examples, there is a mark down file labeled `data_output_dict.md` that acts as a dictionary for the excel sheet of array variables produced in simulation.
