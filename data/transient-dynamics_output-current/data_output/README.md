# WHAT
The folder upon completion of a single execution of the Jupyter notebook will be populated by the folder `generated-data`. This folder will contain the stored data of the standard Lotka-Volterra predator-prey model and/or Lotka-Volterra predator prey model with carrying capacity labeled `standard_model` and `carrying_capacity_model`. Within these subfolders storing figures (plots and graphs) and results (array variables and non-array variables/analysis stored) labeled figures_(model type) and results_(model type). If an input is not used or the segments for the other model are not ran, these folders will be remain empty.
