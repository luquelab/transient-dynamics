Scenario 3 transient example (Environmental enriched coastal like case)
Copy these parameters into the input parameter section to produce the results in folder

Growth rate parameter of bacteria (1/hr)
r = 0.1

Adsorption rate, the rate at which phages can enter a bacteria (ml/hr)
a = 3.0 * 10**-9

Burst size, the amount of viral particles generated by the bursting of a bacteria cell (VLP/burst)
c = 50

Decay rate of phage (1/hr)
m = 0.1

Observational time, the elapsed time during the simulation (hr)
tobs = 300

Initial conditions/populations
bi = 2.65*10**3 #bacteria (cells/ml)
pi = 4.93*10**4 #phage (phages/ml)

The alpha level, or the amount of change that is perceptible by the viewer
reference_level = 0.10

The weight value above which the processes will be considered relevant, should be kept at one
thresholdlevel = 1.0
